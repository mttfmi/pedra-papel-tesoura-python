# 🪨📄✂️ Pedra, Papel e Tesoura em Python

Jogo de Pedra, Papel e Tesoura para dois jogadores, rodando no terminal e feito do zero em Python.

## Funcionalidades

- Partida em **melhor de 3**, com placar atualizado a cada rodada
- Jogadas **escondidas** com `getpass`: dois jogadores podem jogar no mesmo computador sem ver a jogada do outro
- **Validação de entrada**: só aceita pedra, papel ou tesoura
- Opção de **jogar de novo** ao final da partida

## Conceitos praticados

Funções · Condicionais · Loops `while` · Validação de entrada · f-strings · Bibliotecas padrão (`os`, `getpass`)

## Como executar

Requer Python 3 instalado.

```bash
python jogo.py
```

> O comando de limpar a tela (`cls`) funciona no Windows. No Linux/Mac, troque por `clear`.
